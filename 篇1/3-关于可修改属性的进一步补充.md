## 人物

如果你把鼠标悬停在上面过的话，zj(ld)中的zj是一个列表(数组)，ld则是我们使用对象的下标，如果我们改一下下标就可以改别人的属性了（甚至用别人的坐标发射弹幕），目前能用的下标只有ld（自机），tgt_ind（敌机）以及tgt_pool列表（敌机列表）中的值

我们常用的值大致如下

```vbnet
With zj(ld)
    .anti_time_stop'剩余时停抗性时间，每一游戏帧都降低1，具体效果在之后会讲解
    .bound_radius'碰撞墙壁时的半径
    .bound_rule'碰撞墙壁的方式
    .ctrl'按键
    .dad'自机的编号，现版本和ld是一样的，之后可能会有变化
    .speed_2'第二速度，用于达成类似于被击退的效果
    .mov_ang_2'第二速度方向
    .decay_2'第二速度衰减速度
    .def_reserve
    .dup
    .graze_gauge
    .graze_r
    .health
    .health_para
    .hit_para
    .hit_r
    .index
    .invincible_t
    .layer_list
    .length
    .mark_index'判定点的弹幕ID
    .melee_decelerate_t
    .move_multi
    .move_para
    .my_gauge
    .opacity
    .profile_name
    .rt_line
    .scale_x
    .scale_y
    .shape
    .source
    .tm
    .weapon_jam_t
    .x
    .y
End With
```

## 弹幕

与自机的下标相同，它也通过下标（弹幕ID）来指示究竟是哪个弹幕

通常创建弹幕时我们使用如下格式，以修改弹幕的属性

```vbnet
'在Char_Pshoot()开头
Dim ind As Integer
'之后
If ... Then
    ind = Bini(...)'保存Bini()函数的返回值，它会返回它创建的弹幕的ID
    dm(ind).sharp = Collide_shape.rect'修改这个弹幕的形状
End If
```

弹幕与自机有许多类似作用的属性，就不过多说明了，这里说明一些与自机的属性不同的地方

```vbnet
With dm(Bindex)
    .
End With
```

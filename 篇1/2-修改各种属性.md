## 基础语法

### 注释

首先映入眼帘的应该是绿色的`枚举定义`和一大堆等号，前面有一个 ' 符号，众所周知计算机是英文写的，这个中文当然不是给计算机看的*（这里忽略了一些特殊情况，在某些情况下计算机可以看中文）*，这个中文的用处是告诉看这份文件的程序员一些东西，例如接下来几行是用来干什么的，接下来的函数有什么用，使用 ' 符号就可以让一行内容被视为注释，让计算机忽略掉，有时也用这种方法去掉一部分游戏代码但是保留代码内容供人看

如果需要注释或取消注释多行内容，可以使用快捷键CTRL + /（注释或取消注释内容）或者CTRL + K, CTRL + C（这里是两次组合键，注释内容），CTRL + K, CTRL + U（取消注释）

### 引用简写

首先看到第一行的

```vbnet
Imports All_codes
```

我们接下来会大量使用All_codes命名空间下的函数与类，如果直接写函数或类名字的话，VS也不知道你这是从哪来的，在文件最前面添加这个：Imports 命名空间，就可以告诉VS接下来不认识的内容要在哪里去找

什么，你问我什么是`命名空间`，`函数`，`类` ？那就继续看下去吧

### 命名空间

在C#里，命名空间的作用就像是文件路径，可能你有很多个相同名字的文件，但是他们不在同一个路径下，就是不同的文件。

编译器内部在寻找类的时候，会通过引用的命名空间来寻找，比如`Def_char`这个类名不是vb的语法词汇，就会在上面引用的All_codes中找这个名字

假如没有在文件开头添加引用，就必须写`All_codes.Def_char`来告诉编译器从`All_codes`中找

### 类名

再往下看，就是类名了

```vbnet
public class Char_class
```

~~类名就是类的名字~~，类名是对一系列数据与函数的格式的描述，有时类也可以存储数据，类可以通过 `New 类名()`来新建一个`实例(对象)`，实例(对象)则是我们通常用来存储数据的`容器`，在这里，我们创建了一个类名叫`Char_class`，这里面（`End Class`之前）会描述用它创建的对象会有怎样的数据与怎样的函数。

后面的

```vbnet
Inherits Def_char
```

则是这个类的继承，也就是标记了这个类是弹幕，自机还是图层等等的一个说明，暂时先这么理解，我们以后会讲到。

### 函数

跳过一部分，我们看到

```vbnet
Public Sub New()
```

这是一个用于新建实例的函数，函数是一个入口，当被调用时就会从这里开始运行接下来的代码，sub说明这个函数没有返回值，New则是函数的名字，当我们用这个类创建一个对象时就会从这里进来，然后在`End Sub`处回去，当然还有有返回值的函数，我们用到再说。

### 缩进

你可能注意到了，这些代码是按照一定的格式写出来的

每个代码块都比包括它的代码块要往后4个空格的距离（VS里按Tab键缩进），如果不按照这个格式写，代码能运行嘛？当然能，但是**千万不要这么做**

之所以有缩进，就是为了能让你看清楚这一段代码是属于哪个**块**的，比如`Public Sub New()`所包含的代码块就属于这个`Public Class Char_class`类下的代码

**代码缩进**非常重要，这不是可选的，而是**每个Mod制作者**都应该遵守。VS也有提供格式化代码的方案，详情可以百度。

属性修改
----

现在，你已经具备了写Mod的基本知识了，现在你最关心的是如何修改人物了吧，那么往下看到

```vbnet
        name_string = "范例人物"
        short_name = "sample"
        description = "示范用"
```

这段代码。它的作用就是设置人物的在选择界面的属性，等号后面是设置用的值，前面是被设置的内容，现在，你可以根据游戏内的表现去修改几个值（别忘了双引号），看看效果如何。修改完毕后，记得先编译再运行。

再往下看到`Char_ini`函数

```vbnet
        zj(ld).my_gauge = {
            New Gauge(3, 3, 0.1, 0, 60, "A-高速弹幕")
        }
```

这段代码的含义是设置自机`zj(ld)`的`my_gauge`属性（弹药槽）为新的列表`{}`，内容为一个 `New Gauge(3, 3, 0.1, 0, 60, "A-高速弹幕")`，你可以在这个内容后面加一个`,`（逗号），然后再添加一个新的Gauge对象在新的一行（回车添加一行）里（例如复制一遍），然后再看看效果

你会注意到 `New Gauge(...)`中`...`中有一大堆数字和一串文字，你在把前后括号写好以后在里面打个`,`（逗号）就可以看到VS给出提示这里要填什么，试试随便改点什么，看看原本的"A-高速弹幕"弹药槽会有什么变化

再往下，比较重要的有

```vbnet
Bini(pdm(1, 1), .x, .y, .P_ang, 14, .dad, 3)
```

与

```vbnet
If .Skill(.ctrl.a, Sk.A) Then'这里的.ctrl.a是zj(ld)对象下的数据，内容是游戏读取的按键这是按下A，这里的Sk.A相当于0，你可以添加弹药槽后改成1试试
...
End If
```

同理，也可以看看VS给的提示得知参数的作用

# 对战逻辑

本篇介绍纷乱的源代码中关于对战逻辑的线。

刚打开反编译后的代码，可能会有点懵不知道该去干啥，这里给出游戏内最主要的规则部分。

首先需要说明一点，游戏的主循环在Core.Mainloop()函数中，而这里所说的是Game_rule.Battle_run()。

注意：在后续的BOSS版本更新后，可能会出现改为使用Game_rule_boss类中的函数。

先贴源码

```vbnet
Public Overridable Sub Battle_run()
        If Core.time_stop > 0 Then
            Dim num As Integer = 1
            Do
                If Core.zj(num).anti_time_stop > 0 Then
                    Core.zj(num).character.Char_Pregen()
                End If
                num += 1
            Loop While num <= 2
            Dim num2 As Integer = 1
            Do
                If Core.zj(num2).anti_time_stop > 0 Then
                    Core.zj(num2).character.Char_Pmove()
                End If
                num2 += 1
            Loop While num2 <= 2
            Dim num3 As Integer = 1
            Do
                If Core.zj(num3).anti_time_stop > 0 Then
                    Core.zj(num3).Pshoot()
                    Core.zj(num3).anti_time_stop -= 1
                Else
                    Core.zj(num3).Pshoot_in_time_stop()
                End If
                num3 += 1
            Loop While num3 <= 2
        Else
            Core.zj(1).character.Char_Pregen()
            Core.zj(2).character.Char_Pregen()
            Core.zj(1).character.Char_Pmove()
            Core.zj(2).character.Char_Pmove()
            Core.zj(1).Pshoot()
            Core.zj(2).Pshoot()
            Bullet.B_overall_move()'弹幕的各种移动
            Bullet.B_overall_hit()'弹幕命中判定
        End If
        Core.time_stop = Math.Max(Core.time_stop - 1, -1)'扣除时停时间
        Judge_winner()'判断胜者
        Common_funcs._D.Shake_screen()'屏幕震动特效
        Core.t += 1
End Sub

```

其中关于时停时的内容冗长而奇怪，我们直接看非时停时，从Char_Pregen到Char_Pmove到Pshoot到B_overall_move与B_overall_hit，这就是主要对战时序，时停时则添加了对抗时停的剩余时间的判定，以及去掉了弹幕相关的内容。

这时候可能会有人想问为什么Pshoot前面没有Core.zj(x).character.，点开看，这是因为其中有对哑火时间的判定，在我们重载的函数中是没有的。

接下来是B_overall_move()的源代码

```vbnet
Public Shared Sub B_overall_move()
        Dim num As Integer = Core.zj.Length - 1
        For i As Integer = 1 To num
            Dim num2 As Integer = Core.zj(i).layer_list.Length - 1
            For j As Integer = 0 To num2
                Core.zj(i).layer_list(j).main_cursor = 0
                Do While Core.zj(i).layer_list(j).main_cursor <= Core.zj(i).layer_list(j).bullet_list.Count - 1
                    Dim bullet As Bullet = Core.zj(i).layer_list(j).bullet_list(Core.zj(i).layer_list(j).main_cursor)
                    bullet.Omove()
                    If bullet.type <> 0 AndAlso bullet.Obound() Then
                        bullet.Bdeath(1.0)
                    End If
                    Core.zj(i).layer_list(j).main_cursor += 1
                Loop
                Core.zj(i).layer_list(j).main_cursor = 0
            Next j
        Next i
End Sub


```

好多，不过大部分其实是用于历遍整个人物与图层的，其中最重要的部分是

```vbnet
bullet.Omove()
If bullet.type <> 0 AndAlso bullet.Obound() Then
    bullet.Bdeath(1.0)
End If
```

其中的bullet是每一个弹幕，接下来我们看到Omove()函数

```vbnet
Public Overrides Sub Omove()
	MyBase.Omove()
	If feature IsNot Nothing Then
		feature.Bmove()
	End If
	If character IsNot Nothing Then
		character.Char_Bmove(index)
	End If
	age += 1
End Sub
```

`MyBase.Omove()`就是正常的匀速直线运动部分，`character.Char_Bmove(index)`与`character.Char_Bmove(index)`就是弹幕特殊运动的两种方式

# 自定义额外资源

本篇讲解加载自定义的图片素材，音效素材，以及一些其他的素材（如消弹圈之类的不在pdm中的素材），以及其的释放。

加载自定义自机贴图（快捷版加载图片）

```vbnet
'在Char_ini()
Load_zj_custom()
```

加载贴图

```vbnet
'在Char_class
Private Shared loading As Boolean = True'用于防止多次加载同一个资源的标签
Public Shared pho As Photo'用于存放图片的变量
'在Char_ini()
If loading Then
    pho = New Photo(...)'按参数提示填写
End If
'在Char_Pshoot()
Bini(pho, ...)'在Bini时使用存放的图片
'在
```

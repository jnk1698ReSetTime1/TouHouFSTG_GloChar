# 位移

通常我们使用.mov_ang和.speed操作位移，其位移的逻辑就大致如下

```vbnet
'Bmove
.vx = .speed * Cosd(.mov_ang)
.vy = -(.speed * Sind(.mov_ang))'屏幕的左上角是(0, 0)，y轴正半轴朝下，但你游的角度却是按y轴正方向朝上来的，所以需要加个负号
.x += .vx
.y += .vy
```

# 追踪

```vbnet
'Bmove
.P_ang += Chase(.P_ang, .Snipe_ez(), 3)'使用Chase限制旋转距离
.mov_ang = .P_ang
```

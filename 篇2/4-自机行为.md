# 自机行为

本篇讲解重载自机的初始化，中弹后，在时停时，恢复弹药时等不同情况触发的函数。

## 常用的自机行为

```vbnet
'非函数的重载
Public Overrides Property Xtrick As Double'用于骗过狙的x，瞄准时的被瞄准方会对应这个x
Public Overrides Property Ytrick As Double'用于骗过狙的y，瞄准时的被瞄准方会对应这个y
'常规需要重载的
Public Overrides Sub Char_ini(leader_in As Integer)'人物实例的初始化，这时候不可以有弹幕
Public Overrides Sub Char_Pshoot()'常规的每帧一次的函数，一般在这里写技能
Public Overrides Sub Char_Pshoot_in_time_stop()'Char_Pshoot在时停时的版本，时停时才会运行
Public Overrides Sub Char_Bmove(Bindex As Integer)'第一篇有说
Public Overrides Sub Char_Bdeath(Bindex As Integer, more As Double)'第一篇有说
'其他的有时会重载的函数
Public Overrides Sub Char_Pmove()'自机的移动函数，与弹幕不同的是这里包含了正常移动时的部分
Public Overrides Sub About_melee_accelerate()'被近战后会有一段减速，这里是用来恢复的部分
Public Overrides Sub Char_create_hit_sign()'创建判定点弹幕，这个时候是最早的可以发弹的时候
Public Overrides Sub Char_Pregen()'自机的每帧回弹
Public Overrides Sub Attack_eff(blt_ind As Integer, hitted_zj_ind As Integer)'弹幕命中敌人后的操作，调用Bdeath(0)也在这里面
Public Overrides Sub Char_Phitted(target As Integer)'被命中后的行为，用来调用接下来两个函数
Public Overrides Sub Def_hit_melee(target As Integer)'被近战命中后的操作，例如在字幕中弹出伤害
Public Overrides Sub Def_hit_shoot(target As Integer)'被弹幕命中后，同上
Public Overrides Sub Dispose()'如果有加载的资源，可以在这里取消加载
'其他函数大多和绘图相关，就不加在这里了
Public Overrides Function Prepair_char_entry() As Entry_character'用于生成人物配置菜单，在下一篇末尾详解
Public Overrides Function Read_initial_setting(Optional which As Integer = 1) As Byte()'加载人物配置并网络同步
Public Overrides Sub Manage_invincible()'无敌时的自机贴图闪烁在这里
Public Overrides Sub Adjust_in_Judge_winner()'游戏内修正判定点，判定点的缩小（低血量）和恢复（被修改）都在这里
```

所有可能重载的非绘图函数基本就在这里了，他们的触发条件也基本在备注中写明了，~~那么本篇就到这里了~~

还有一件事，这些函数有许多都是每帧运行，那他们的顺序呢，关于这一点，我会在第三章中细说。

类似人物的被动啥的基本都会在这里做，接下来讲解一点值得注意的地方

任意的绘图函数在时停时也会绘制，包括重载图层时重载的绘图函数

`Char_Pregen`和`Char_Pmove`在哑火时仍然运行，如果有什么常态特性（可以额外添加条件）比较推荐加在这里

`Char_Pshoot`则哑火与时停时不能运行

`Char_Pshoot_in_time_stop`在哑火与非时停时不能运行，与上面那个相辅相成

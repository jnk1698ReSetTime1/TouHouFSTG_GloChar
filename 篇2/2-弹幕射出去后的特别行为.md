在第一篇中，我们从0开始搭建了一个通用模板，而在后来的更新中，~~崩砖在游戏内内置了这套模板~~我们可以用更加现代化一点的方式。

第一篇提到，我们可以用dm(Bindex).feature，接下来我们来从零开始。

VS提示我们， dm(Bindex).feature是Def_feature类的，我们新建一个类重载它。

```vbnet
Public Class A
    Inherits Def_feature
End Class
```

然后就报错了`类“A”必须声明一个“Sub New”，原因是它的基类“Def_feature”没有不使用参数就可以调用的可访问“Sub New”。`   把鼠标移到红色波浪号的A上，点开`显示可能的修补程序`然后点生成构造函数，啪，就不报错了。

```vbnet
Public Class A
    Inherits Def_feature
    Public Sub New(index As Integer)
        MyBase.New(index)
    End Sub
End Class
```

现在这个类里面还什么特别的都没有，基本就是原本的Def_feature。

我们尝试重载，发现有3个可能用得到的， Bmove()，Bdeath()，Dispose()，

前两个与第一篇的类似，第三个则比较特别，是用来释放资源的，现在可以不需要学是用来干什么的。然后我们就写成这样了。

```vbnet
Public Class A
    Inherits Def_feature
    Public Sub New(index As Integer)
        MyBase.New(index)
    End Sub
    Public Overrides Sub Bmove()

    End Sub
    Public Overrides Sub Bdeath(more As Double)

    End Sub
End Class
```

这里没有index（弹幕ID），弹幕实例使用blt引用。

```vbnet
With blt
...
End With
```

这与dm(Bindex)是类似的。

同时这里不再需要在意type（原因后面说）。

我们把前面提到的例子再写一遍。

```vbnet
Public Class A
    Inherits Def_feature
    Public Sub New(index As Integer)
        MyBase.New(index)
    End Sub
    Public Overrides Sub Bmove()
        With blt
            .speed += 0.02
            If .age > 60 Then
                .Bdeath(3)
            End If
        End With
    End Sub
    Public Overrides Sub Bdeath(more As Double)
        With blt
            If more = 3 Then
                .B_real_delete()
            End If
        End With
    End Sub
End Class
```

接下来我们设置新弹幕的feature。

```vbnet
'在Char_Pshoot
ind = Bini(...)
dm(ind).feature = New A(ind)
```

注意到，这里没有设置character，在读完第三第五章前这里最好不设置character和type。

然后编译启动，就可以看到弹幕效果了。
